# Supply Chain Procurement Analytics and Spend Intelligence Chrome Extension

A Chrome extension for procurement managers and supply chain analysts browsing supplier websites and B2B marketplaces. Enriches supplier pages with real-time financial health scores, Dun and Bradstreet risk ratings, ESG compliance indicators, and historical price variance data from internal procurement records. Tracks viewed suppliers in a watchlist, generates competitive bid comparison tables from browsed supplier quotes, and exports procurement intelligence reports as Excel workbooks.

## Installation

### Chrome
1. Download and extract the ZIP
2. Go to `chrome://extensions/`
3. Enable "Developer mode"
4. Click "Load unpacked" and select the extracted folder

### Firefox
1. Download the Firefox version
2. Go to `about:debugging`
3. Click "Load Temporary Add-on"
